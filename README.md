# Ithy.ai

The public landing page for Ithy, Inc.

## Hosting

GitHub Pages publishes `main` from the repository root. The custom domain is `ithy.ai`; `CNAME` preserves that setting. `.nojekyll` serves the HTML directly.

## Editing

Edit `index.html` and push to `main`. No dependency install or build is required. The page uses local SVG/PNG/ICO brand assets, inline CSS and a small progressive-enhancement script for copying the contact email. It has no analytics, external fonts or third-party scripts.

`favicon.svg` is the editable favicon source. `assets/brand.svg` is the transparent site mark; the related gold/teal geometry is distinct from the original Ithy.com logo. Browser icons, Apple touch icon, web manifest and social preview are served as ordinary static files. `robots.txt` and `sitemap.xml` identify the canonical public page.

Contact links point to `wluk@ithy.ai`. The public business link points to `https://ithy.com/`.
